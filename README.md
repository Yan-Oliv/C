Exercícios em **C** da disciplina de Programação Estruturada (Sistemas de Informação, 2021/1 · 2º semestre).

## Conteúdo

| Arquivo | Descrição |
|---|---|
| `Estruturas de Repetição/estruturasderepeticao.c` | Exercícios de estruturas de repetição (`for`, `while`, `do…while`) |
| `Estruturas de Repetição/*.txt` | Enunciado e anotações do exercício |

## Como compilar

```bash
gcc "Estruturas de Repetição/estruturasderepeticao.c" -o repeticao
./repeticao
```

> O código usa `system("color …")` e `setlocale`, pensados para o terminal do Windows.
